# Our Cinema — love-movies

A tiny two-person film club: shuffle a curated shelf (romance, cozy, artful,
animated), filter by mood, share a pick (`?m=title-slug`), and mark films
watched into a local log.

Live: https://menaammarpro.github.io/love-movies/

## Storage key

- `mena-movies` — `{ watched:[{title,at}], mood:"all"|"romantic"|..., pick:index }`

Made with love, just for you ♥
